ORTAOKULLUYUZ — VERCEL + NEON POSTGRES KURULUMU
=============================================
Eski Vista Panel hostingi çöktüğü için site Vercel'e taşındı.
PHP/MySQL kalmadı: backend Node.js sunucusuz işlevler + Postgres.

ADIM 0 - GEREKEN HESAPLAR (ücretsiz)
  1. GitHub hesabı (kodları yüklemek için)
  2. Vercel hesabı (vercel.com, GitHub ile giriş)
  3. Neon hesabı (neon.tech, ücretsiz Postgres)
  4. Brevo hesabı (brevo.com, günlük 300 e-posta bedava)

ADIM 1 - KODLARI GITHUB'A YÜKLEYİN
  1. GitHub'da yeni, ÖZEL (private) bir repo açın.
  2. Bu klasörün İÇİNDEKİLERİNİ (tüm html, css/, js/, img/, api/,
     package.json, db-postgres.sql) repoya yükleyin.
  3. node_modules YÜKLEMEYİN (Vercel kendisi kurar).

ADIM 2 - NEON'DA VERİTABANI AÇIN
  1. neon.tech > New Project (bölge: EU / Frankfurt önerilir).
  2. Database adı varsayılan (neondb) kalabilir.
  3. Connection string'i kopyalayın (pooled olanı tercih edin):
     postgresql://kullanici:sifre@ep-xxx.eu-central-1.aws.neon.tech/neondb?sslmode=require

ADIM 3 - VERCEL'E BAĞLAYIN
  1. vercel.com > Add New > Project > GitHub reponuzu seçin > Import.
  2. Framework: "Other" (varsayılan), Root: ./ , Build: boş bırakın.
  3. Environment Variables bölümüne şunları ekleyin (Production):
       DATABASE_URL       = Neon connection string (ADIM 2)
       JWT_SECRET         = uzun rastgele metin (örn. 40+ karakter)
       SETUP_KEY          = kurulum anahtarı (uzun rastgele metin)
       EMAIL_MODE         = brevo
       BREVO_API_KEY      = Brevo > SMTP & API > API Keys
       BREVO_SENDER_EMAIL = Brevo'da onayladığınız gönderici adresi
       SENDER_NAME        = Ortaokulluyuz
       GOOGLE_CLIENT_ID   = Google Cloud'dan alınan web istemci kimliği
                            (boş bırakılırsa Google düğmesi görünmez)
       SMS_MODU           = kapali  (NetGSM kullanacaksanız: netgsm)
       NETGSM_USERCODE    = NetGSM kullanıcı adı (usercode)
       NETGSM_PASSWORD    = NetGSM şifresi
       NETGSM_HEADER      = NetGSM'de onaylı mesaj başlığı (örn. ORTAOKUL)
  4. Deploy'a basın. 1-2 dakikada siteniz yayında olur.

ADIM 3B - GOOGLE İLE GİRİŞ (isteğe bağlı)
  1. console.cloud.google.com > yeni proje > APIs & Services >
     OAuth consent screen: harici (External), uygulama adı + e-posta.
  2. Credentials > Create Credentials > OAuth client ID > tür: Web.
     Authorized JavaScript origins: https://siteniz.vercel.app
     (Yerel test için http://localhost:3000 de eklenebilir.)
  3. Oluşan "xxx.apps.googleusercontent.com" kimliğini kopyalayıp
     Vercel'de GOOGLE_CLIENT_ID olarak kaydedin, Redeploy yapın.
  4. Sitede giriş penceresinde Google düğmesi belirir. Google ile
     giriş yapanın e-postasına yine doğrulama kodu gider; kodu giren
     hesaba bağlanır (yeni ise hesabı otomatik açılır).

ADIM 3C - TELEFONLA KAYIT / SMS (isteğe bağlı, ÜCRETLİ)
  Varsayılan kapalıdır (SMS_MODU tanımsız) ve kayıt ekranında telefon
  sekmesi görünmez; hiçbir ücret oluşmaz. Açmak isterseniz NetGSM'den
  hat + onaylı başlık alıp SMS_MODU=netgsm ve NETGSM_* değerlerini girin.

EK A - KURUMSAL E-POSTA (info@alanadiniz)
  NOT: x.dpdns.org gibi baskasina ait alan adinin alt adresinde DNS
  oynayabilmek YETMEZ. Mail icin su kayitlar gerekir: alici tarafta MX,
  gonderici tarafta SPF/DKIM TXT. DDNS saglayicilarinda bunlar ya kapali
  ya da eksik olur; olsa bile Brevo/Google/Cloudflare "zone sahibi
  degilsiniz" diye reddeder, spam filtreleri DDNS alan adlarini zaten
  guvenilmez sayar. Ayrica AdSense ve okul guveni icin de gercek alan
  adi sarttir. Yani cozum yine kendi alan adinizdir (asagidaki adimlar).
  Tek sart kendi alan adinizdir. UCRETSIZ SECENEKLERIN GERCEGI:
  - Freenom (.tk/.ml/.ga): OLDU, calismiyor. Artik bedava domain dagitan
    duzgun kayit sirketi yok.
  - eu.org gibi gonullu altyapilar: onay haftalar surer, guvenilirligi
    dusuktur; AdSense ve kurumsal mail yine kabul etmez. Tavsiye edilmez.
  - EN YAKIN COZUM: .xyz / .top / .site gibi uzantilarda ilk yil
    kampanyalari (Porkbun, Namecheap, Cloudflare'da ~1-2 dolar, yani bir
    ekmek parasi). Bu GERCEK alan adidir: AdSense, mail, SSL hepsi olur.
    Yenilemesi yillik ~10 dolardir.
  - Ogrenciyseniz: GitHub Student Pack ile .me uzantisi 1 yil bedava.
  (yillik ~10-13 dolar; Natro/Isimtescil/Turhost
  veya Cloudflare/Porkbun'dan alinir; DNS'i Cloudflare'e baglayin).
  Sonrasi tamamen UCRETSIZDIR:

  1) MAIL ALMA — Cloudflare Email Routing (bedava):
     Cloudflare panel > alan adiniz > Email > Email Routing > Enable.
     Catch-all kuraliyla info@alanadiniz gelenleri kisisel Gmail'inize
     yonlendirin. MX kayitlarini otomatik yazar. Test icin kendinize
     mail atin, Gmail'e dustugunu gorun.

  2) MAIL GONDERME — Brevo (zaten kullaniyorsunuz, bedava 300/gun):
     Brevo > Senders & IP > Domains > Add a domain > alan adinizi yazin.
     Verdigi SPF/DKIM TXT kayitlarini Cloudflare DNS'e ekleyip Verify
     edin. Sonra Vercel'de BREVO_SENDER_EMAIL = info@alanadiniz yapip
     Redeploy edin. Artik dogrulama kodlari kurumsal adresten gider ve
     spam'a dusme orani da duser.

  3) GMAIL'DEN KURUMSAL ADRESLE YAZMA (bedava):
     Gmail > Ayarlar > Hesaplar > "Postalari su adresten gonder" >
     yeni adres ekleyin. SMTP sunucusu: smtp-relay.brevo.com:587,
     kullanici adi: Brevo giris e-postaniz, sifre: Brevo > SMTP & API >
     SMTP anahtari. Artik Gmail arayuzunden info@alanadiniz olarak
     yazip cevaplayabilirsiniz; ayri posta kutusu parasi odemezsiniz.

  4) SITEYE ISLEME:
     - gizlilik.html'deki info@ortaokulluyuz.com adresini gerceginizle
       degistirin.
     - Vercel > Project > Settings > Domains > alan adinizi ekleyin,
       gosterdigi DNS kaydini Cloudflare'e girin. SSL otomatik gelir;
       bu, AdSense onayi ve okul guveni icin de sarttir.

  Ucretli alternatif (sart degil): Google Workspace / Microsoft 365
  (~7 dolar/kullanici/ay) gercek posta kutusu verir; yukaridaki
  ucretsiz duzen cogunlukla yeterlidir.

EK B - REKLAMLA GELİR (AdSense)
  Pakette reklam altyapısı HAZIR ama KAPALI gelir (js/reklam.js).
  Açmadan önce bilmeniz gerekenler:
  - Onay şart: AdSense; özgün içerik, Gizlilik Politikası (sitede
    gizlilik.html hazır), iletişim bilgisi ve düzenli trafik ister.
    Başvuru öncesi info@... adresini gerçek adresinizle değiştirin.
  - Kazanç beklentisi: Türkiye eğitim trafiğinde 1000 gösterim genelde
    0,5-3 dolar bandındadır. Anlamlı gelir için ayda on binlerce
    sayfa gösterimi gerekir; ilk aylarda sembolik olur.
  - Çocuk kitle: 10-14 yaş ziyaretçi ağırlıklıdır. Agresif reklam
    (açılır pencere, tam ekran) hem yasak sınırındadır hem velileri
    kaçırır. Sitedeki 2-3 sakin alan yeterlidir, fazlasını eklemeyin.
  Açmak için:
  1. google.com/adsense > başvurun; onaylanınca Publisher ID
     (ca-pub-...) ve 2 reklam birimi Slot ID'si alın.
  2. js/reklam.js içindeki acik/client/slot satırlarını doldurun.
  3. Yeniden deploy edin. Reklamlar belirlenen sakin alanlarda çıkar.

ADIM 4 - KURULUM SİHİRBAZI
  Tarayıcıda:  siteniz.vercel.app/api/setup
  - SETUP_KEY + yönetici adı/e-posta/şifreyi girin, Kurulumu Başlat.
  - Tablolar kurulur, yönetici oluşur, örnek forum taşınır.
  - "Kurulum tamamlandı" sonrası bu adres bir daha çalışmaz.

ADIM 5 - KONTROL
  - Sesli görüşme modülü, güncel sürümde eksik sesli tablolarını ilk kullanımda
    otomatik oluşturur. Bu yüzden eski veritabanında /api/setup tekrar çalıştırılmamış
    olsa bile sesli arama tabloları oluşturulabilir.
  - Ana sayfanın üst şeridinde "Ortak veritabanına bağlı" yazmalı.
  - Yönetici girişi + Yönetim Paneli > Test E-postası ile maili ölçün.
  - Özel alan adınız varsa: Vercel > Project > Settings > Domains.

ÖNEMLİ FARKLAR (eski sürüme göre)
  - Soru görselleri artık dosyaya değil, veritabanına (base64) kaydedilir;
    uploads/ klasörü kaldırıldı. Boyut sınırı 2 MB.
  - Parolalar bcrypt, oturumlar JWT çerezi ile tutulur.
  - E-posta yalnızca Brevo HTTPS API ile gider (SMTP modu yok; Vercel'den
    mail portları kapalıdır). Hotmail şifresine gerek kalmadı.
  - Eski MySQL verileri çöken hostingde kaldı; site sıfırdan başlar.
    Üyeler yeniden kayıt olur, roller Yönetim Paneli'nden atanır.
  - Production alan adında sunucuya ulaşılamazsa yerel auth/data moduna düşmez; güvenli biçimde bağlantı hatası gösterilir. localhost testinde yerel fallback korunur.

GÜVENLİK GÜNCELLEMESİ
---------------------
- Üretim API çağrıları /api/gateway üzerinden gider; eski /api?islem= yolu kapalıdır.
- DB tabanlı özel CAPTCHA ve kısa ömürlü HttpOnly güvenlik geçişi kullanılır.
- CAPTCHA için DB tabloları ilk API çağrısında da otomatik hazırlanır; yine de /api/setup çalıştırmanız önerilir.
- Vercel'de SECURITY_PEPPER için ayrı, güçlü bir secret tanımlayın. Örnek: openssl rand -base64 48
- ALLOWED_ORIGIN isteğe bağlıdır; öneri: https://ortaokulluyuz.dpdns.org
